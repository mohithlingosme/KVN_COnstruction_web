# KVN Construction — Admin Guide

Sign in at `/admin/login.php` with an active account whose role is `admin` or `super_admin`.

## Leads

Use **Leads** to view incoming enquiries, edit their contact details, assign an owner, and change the pipeline status. Record follow-up notes before moving a lead so the next team member has context.

## Estimator

In **Estimators**, manage packages, material/rate entries, and estimate requests. Keep package status set to `Active` only for offers visible to customers. Review each request before contacting the customer; its plot area, floor count, selected package, and calculated cost are retained with the request.

## Testimonials and blogs

Use **Testimonials** to approve only verified customer submissions before they appear publicly. Use **Blogs** to create drafts, add a title, content, image, and SEO metadata, then publish only after previewing the page.

## Good operating practice

Use a separate named administrator for each staff member, sign out after use, and never share credentials. Before changing prices or publishing content, take a database backup and verify the public page in a private browser window.
