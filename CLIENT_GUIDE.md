# KVN Construction — Client Guide

Register or sign in through the client portal using the mobile number or email linked to your project.

## Projects and milestones

The dashboard lists active projects and their current status. Open a project to see milestones, work updates, gallery images, and shared documents. Contact the project team if any milestone or document does not match the agreed scope.

## Documents and payments

Upload only project-related files in the project document area. Confirm that the file name and preview are correct after upload. Invoices and payment status appear in the portal; use the payment instructions shown on the invoice and retain the confirmation reference.

## Support

Create a support request from the portal for access issues, billing questions, or project updates. Include the project name and a concise description so the team can route it promptly.
